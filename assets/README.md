# assets — GazeScroll 소개 이미지

루트 `README.md`가 참조하는 데모 이미지 폴더입니다. 아래 파일명 그대로 넣으면 README에 바로 표시됩니다.
오버레이는 투명 클릭스루라 **실제 앱 위에서 라이브 캡처**해야 합니다(ScreenToGif 권장, 정적은 Win+Shift+S).

현재 포함된 이미지:

| 파일 | 내용 | 형식 |
|------|------|------|
| `hero.gif` | 유튜브 긴 페이지 응시 스크롤(대표 이미지) | GIF 880px·8fps·4.6MB |
| `dwell.gif` | GitHub README 페이지 응시 스크롤 | GIF 760px·10fps·2.7MB |
| `settings.png` | 설정 패널 모양 탭(언어·색 팔레트·게이지·버튼 모양) | PNG 1000px |
| `winlist.png` | 붙일 창 허용목록(현재 창 목록에서 대상 지정) | PNG 720px |

향후 추가 후보(선택): `attach.gif`(창 자동 추종), `usecase-phone.gif`(휴대폰 원격제어).

캡처 팁: 깨끗한 바탕화면·개인정보 가림, dwell 시안 링이 잘 보이는 배경, 1080p.
